### Foundational Model
The point of the test is to see if we are just lacking / not having good enough features for the pseudoinverse (to see if with features from a foundation model can predict the result with only pde and bc condition). Basically, we treat the foundation model as the feature extractor and by removing the last layer.

Testing model: PDE-Transformer
Will pass in a(x,y) into model to extract features and then pseudoinverse it.

Still trying to get it working.

1. Feed $a(x,y)$ and forcing term $f$ into the PDE-Transformer. 
2. Extract $\Phi$ which is the features generated. The transformer compressed the grid to $32 \times 32$, so we stretch it back to $128 \times 128$ and then use calculate spatial derivatives of $\Phi$ with finite difference. Then we build the matrix and use pseudoinverse.
